## Summary

The project note describes iBatsID as a continental-scale approach to objective acoustic identification of European bats. It links a standardized reference-call library with extracted call parameters and a hierarchical identification procedure, allowing evidence to support different levels of taxonomic or call-type specificity. The useful emphasis for this dissertation is on repeatable evidence, explicit decision boundaries, and uncertainty rather than a label produced without traceable support.

## Key Methodological Idea

Acoustic identification is treated as a structured tool workflow: compare measurable call properties with a curated reference library, use a hierarchy appropriate to the available evidence, and avoid claiming finer identification than the signal supports.

## Relevance to This Dissertation

The UCL35 project likewise separates event localisation from species certainty. Its output schema records time-frequency geometry, confidence, evidence, and review status. The annotation example library serves a different purpose from iBatsID's reference calls, but follows the same broad principle that repeatable examples and measurable features are preferable to undocumented visual judgement.

## How It Supports the Project Argument

iBatsID helps position the agent as one component in a scientific identification workflow rather than an unconstrained replacement for acoustic expertise. It supports the argument for structured evidence, taxonomic restraint, explicit thresholds, and human review.
