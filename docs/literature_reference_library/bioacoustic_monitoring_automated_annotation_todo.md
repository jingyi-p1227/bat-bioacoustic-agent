## Summary

This theme should establish why acoustic monitoring produces annotation workloads that benefit from automation while still requiring defensible quality control. The project addresses one narrow part of that workflow: event-level strong labelling of bat echolocation calls from spectrograms. Until a real review source is added, broad claims about monitoring scale, manual effort, ecological coverage, or automation accuracy should remain uncited or be removed.

## Key Methodological Idea

Automated annotation should be framed as a reproducible pipeline from audio representation to candidate events, structured labels, evaluation, and review, rather than as an isolated model output.

## Relevance to This Dissertation

The project builds precisely that pipeline: controlled evaluation clips, clean representations, structured event JSON, detector tools, VLM annotation, diagnostics, and fixed metrics.

## How It Supports the Project Argument

A verified review would support the motivation for scalable annotation and explain why error analysis, uncertainty, and human oversight remain important in ecological monitoring.
