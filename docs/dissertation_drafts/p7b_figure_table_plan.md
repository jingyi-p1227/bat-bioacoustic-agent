## Assembly Notes

- All composite figures should use consistent colours and legends for ground truth, matched predictions, unmatched predictions, and missed events.
- Figure captions must state whether results come from the representative diagnostic development subset, the OP_016-only experiment, or the ten-clip held-out set.
- Diagnostic overlays are evidence sources, not model inputs.
- Publication-ready plotting should read canonical CSV or JSON artifacts rather than transcribing values manually.
- Figure numbering is provisional and should be updated when the dissertation chapter order is finalised.
