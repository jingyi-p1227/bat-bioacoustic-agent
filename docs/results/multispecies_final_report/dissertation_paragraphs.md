# Dissertation-Ready Paragraphs

The multi-species experiment used a balanced event-level dataset containing eight species and 240 label-safe samples, with 30 samples per species. Each model-facing image was rendered at 800x600 pixels, and species labels were excluded from filenames, titles, and image content. Stage 1 evaluated species classification under GT-location conditions, where the target event was either centred in the crop or marked with a neutral box. Stage 2 evaluated joint localisation and classification using BatDetect2 proposals in the same event-centred windows.

In Stage 1, qwen3.6 performed poorly on fine-grained species classification. The zero-shot centred-crop condition achieved accuracy `0.129` and macro-F1 `0.051`, while adding a neutral GT box marker improved performance only slightly to accuracy `0.138` and macro-F1 `0.074`. Compact species/acoustic guidance improved the result to accuracy `0.192` and macro-F1 `0.105`, but substantial label collapse remained. Coarse-taxonomy re-evaluation improved Stage 1C to coarse macro-F1 `0.179`, mainly through better Rhinolophus recognition, but Myotis and Ozimops remained poorly recovered.

The Stage 2 experiments showed that localisation and species classification had different failure profiles. Raw sample-level BatDetect2 proposals achieved high recall but produced many false positives. A simple nearest-centre proposal-selection rule, valid because the windows were target-centred, produced strong localisation: on the full 240-sample dataset it achieved IoU>=0.3 F1 `0.888` and 10 ms start-time F1 `0.935`. However, when qwen3.6 was asked only to classify the selected proposal, matched-proposal species accuracy was `0.109` and joint F1 was `0.097`.

These results indicate that, in the controlled event-centred setting, localisation can be substantially improved by deterministic tool use, but fine-grained species classification remains unresolved. The joint task is therefore limited primarily by species-label discrimination rather than by target localisation. For dissertation interpretation, Stage 2C is best presented as a decomposition result: BatDetect2 plus centre-based proposal selection can identify the target event reliably in these windows, but qwen3.6 does not reliably map isolated event-level spectrograms to species labels.
