# Dissertation Paragraphs: Single-Agent Localisation

Across the full 45-clip `Ozimops petersi` benchmark, the strongest result under the primary temporal IoU >= 0.3 protocol was obtained by the BatDetect2 proposal-constrained VLM condition. This condition achieved F1 = `0.785`, improving over both the fixed grid_v2 qwen3.6 baseline and the BatDetect2 proposal-only baseline. The result indicates that qwen3.6 is most effective when used as a constrained verifier and refiner of detector proposals rather than as an unconstrained visual detector.

The P14 conservative best-stack condition was designed to preserve reliable BatDetect2 proposal timing and avoid unsupported onset or offset shifts. It did not improve the primary temporal IoU >= 0.3 score, achieving F1 = `0.735` compared with `0.785` for the previous proposal-constrained VLM. However, it achieved the strongest 10 ms start-time result, with F1 = `0.913`. This shows that conservative proposal preservation improves onset fidelity even when it reduces broader temporal-overlap matching.

The visual preprocessing ablations did not produce a better full45 localisation default. PCEN + grid_v2 underperformed the grid_v2 baseline under the primary protocol, while 0.5s tiled spectrograms improved recall but introduced many false positives. Walters PDF-backed generic acoustic guidance and annotation exemplar retrieval also did not improve aggregate localisation F1. These findings suggest that the most promising single-agent localisation strategy is not richer standalone prompting or visual preprocessing alone, but constrained tool use grounded in reliable detector proposals.
