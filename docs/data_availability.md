# Data Availability

This repository supports an MSc dissertation project at University College
London.

Raw audio recordings and external datasets are not redistributed in this
repository. Original datasets should be obtained from their original providers
and used in accordance with the relevant access conditions, licences and data
use restrictions.

The repository provides the research code and reproducibility materials used
for the project, including:

- source code;
- experiment configurations;
- prompt templates;
- evaluation scripts;
- analysis utilities.

Generated outputs and intermediate files are not included because they are
derived artefacts, including spectrogram images, model inputs, raw model
responses, prediction files, diagnostic figures and evaluation outputs.

Details of the datasets, benchmark construction and data-processing decisions
are described in the dissertation Methods section.
